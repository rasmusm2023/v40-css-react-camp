## Hur kopplas CSS in i React? (målsvar: import './App.css' + className)

Svar: CSS kopplas in i React genom att importeras via import './App.css' och sedan använda className för att tilldela element klasser.

## Hur ser användaren vilka todos som är klara? Peka på klassen i din CSS.

Svar: Via klassen .completed

## Tre steg när stil “inte tar”: spara → import → className → Inspect.

Svar: Se till att filerna är sparade, dubbelkolla att importer finns högst upp. Kolla så att className är angivet på det tänkta elementet. Inspektera och se vad som står i console och se ifall klassen/klasserna blir applicerade.
